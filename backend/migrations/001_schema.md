# Schema v1
SQLAlchemy metadata creates users, audits, datasets, plans, traces, reviews. Natural names are unique; foreign keys reference parent entities. Each trace stores immutable JSON input snapshots. PostgreSQL persists metadata and teaching datasets; the bounded Python operators execute the plan.
`reviews` records a reconciliation: dataset_id / plan_id / baseline_trace_id / candidate_trace_id, status, progress checkpoint (completed steps, rows, per-step summaries), attempts and the atomically published result. The baseline must be a completed trace on the same dataset; the candidate trace is created by the review with its own accepted snapshot. A review is published only when every baseline and candidate step is matched and the new execution self-check passes; otherwise result stays null and status=failed.
